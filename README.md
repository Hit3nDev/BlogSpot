# ✍️ BlogSpot

A responsive multi‑page blog front end built with plain HTML, CSS and JavaScript — home page with a video hero, a blog listing page and an article page.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## Pages

| File | Page |
|------|------|
| `index.html` | Landing page with background video and featured posts |
| `blog-list.html` | All posts listing |
| `blog-post.html` | Single article layout ("The Art of Writing") |

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
